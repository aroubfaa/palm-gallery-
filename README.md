# 🌴 Palm Gallery

A botanical photography explorer that displays stunning palm tree photos from around the world using the **Pexels API**.

---

## ✨ Features

- 🔍 Search palm species by keyword
- 🪟 Pinterest-style masonry grid layout
- 📷 Photographer name badge on every photo
- 🖱️ Hover overlay with photo details
- 🔎 Double-click to open full detail modal
- ⬇️ Load More button (dynamically created)
- ⚡ Skeleton loading animation
- ❌ Error handling with user messages
- 📱 Responsive design for all screen sizes

---

## 🛠️ Tech Stack

`HTML` `CSS` `JavaScript` `Pexels API` `AJAX` `DOM Manipulation`

---

## 📁 File Structure

```
palm-gallery/
├── index.html       # Main HTML structure
├── css/
│   └── style.css    # All styling & responsive design
└── js/
    └── app.js       # AJAX calls, DOM manipulation & events
```

---

## 🖱️ Events Used

| Event | Action |
|-------|--------|
| `click` | Category pills, Search, Clear, Modal close |
| `keyup` | Search on Enter key |
| `keydown` | Escape to close modal |
| `dblclick` | Open photo detail modal |
| `scroll` | Scroll event listener |

1. Clone the repository
```bash

```
2. Open `index.html` in your browser
3. Start exploring palm trees! 🌴
